# 오늘 15시간

첫 화면에 잠들기까지 남은 시간을 크게 보여주고, 활동과 휴식의 실제 시작·마침을 남기는 가족 테스트용 앱입니다. 상세 화면에서는 하루 24시간을 고정된 총량으로 보고 수면·준비·이동·활동을 계획합니다.

- 앱: https://tq6q6v5qpn-alt.github.io/today-15-hours/
- 배포: GitHub Pages, `main` 브랜치 루트
- 저장: 각 기기의 브라우저 `localStorage`
- 백업: 앱 오른쪽 위 `•••` → **전체 기록 백업**

## 구조

- `index.html`: 화면 구조
- `styles.css`: 모바일·접근성 스타일
- `app.js`: 브라우저 화면과 저장소 연결
- `core.js`: 플랫폼 독립 시간 계산·백업 검증
- `tests/`: 핵심 불변식 자동 테스트
- `DATA_CONTRACT.md`: 향후 iOS·Android 공통 데이터 규칙

```bash
npm test
```

첫 화면의 **오늘 잠들기까지 남은 시간**은 설정한 취침 시각까지의 시간으로, 계획을 빼지 않습니다. 취침 시각이 지났으면 0분, 미래 날짜는 예정 취침 시각, 과거 날짜는 0분과 날짜 안내를 보여줍니다. 실제 마친 활동과 휴식만 작은 그림으로 남습니다.

상세 화면 상단의 **하루 미배정 예산**은 `24시간 − 날짜별 수면 − 준비·이동·활동`으로, 이미 지난 시간도 포함합니다. 시간 탭의 **지금부터 열린 시간**은 현재부터 자정까지 수면과 계획이 없는 구간입니다. 미래 날짜는 하루 전체, 지난 날짜는 0분으로 표시합니다. 겹친 구간은 한 번만 세고 자정을 넘은 이전 계획도 반영합니다.

**이 날짜의 수면 설정**에서 기본 9시간과 취침 시각을 조정할 수 있습니다. 기존 날짜별 기록, 저장 키, JSON 백업 스키마 1을 유지합니다. 이름 없는 시간은 낭비 판정이 아닙니다.

격리 브라우저 검사는 Python Playwright와 Chromium 설치가 있는 환경에서 `python3 tests/browser.test.py`로 실행합니다. 테스트는 가상의 주소를 로컬 파일로 연결하고 새 브라우저 컨텍스트의 테스트 기록만 사용합니다.

현재 PWA는 iPhone Safari와 Android Chrome에서 사용할 수 있다. 장기적으로 iOS는 SwiftUI, Android는 Kotlin/Jetpack Compose로 구현하되 `DATA_CONTRACT.md`와 `core.js`의 테스트 결과를 공통 기준으로 삼는다.

## 개발 원칙

- 초 단위 통제, 점수, 연속 출석, 실패 표시를 만들지 않는다.
- 24시간은 늘 고정이며 모든 선택에는 실제 시간 비용이 있다.
- 활동만이 아니라 준비·이동·전환도 시간으로 기록한다.
- 계획과 실제 기록을 분리한다.
- 기록되지 않은 시간을 곧바로 낭비라고 판단하지 않는다.
- 달력의 빈 날짜는 실패가 아니라 기록하지 않은 날이다.
- 자동 감지는 확정이 아니라 사용자가 확인할 제안이어야 한다.
