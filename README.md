# 오늘 15시간

잠들기까지 남은 시간을 보고, 시간 숫자를 터치해 수면과 계획을 조절하며, 실제 활동과 휴식을 기록하는 가족 테스트용 앱입니다. 하루 총량은 24시간이고 수면 길이는 사람이 직접 정합니다. 새 날짜에 9시간이나 연령별 수면값을 자동으로 확정하지 않습니다.

- 앱: https://tq6q6v5qpn-alt.github.io/today-15-hours/
- 운영 배포: GitHub Pages, `main` 브랜치 루트
- 이번 수정: 별도 브랜치의 터치 시간 조절·실제 경로 수정본. 운영에는 아직 반영하지 않았습니다.
- 저장: 각 기기의 브라우저 `localStorage`
- 백업: 앱 오른쪽 위 `•••` → **전체 기록 백업**

## 시간 조절

첫 화면의 큰 시간을 누르면 취침·기상 시각 조절창이 열립니다. 처음에는 두 시각을 직접 선택하고, 설정한 뒤에는 저장된 값을 기억합니다. 네이티브 시각 입력과 큰 ±10분·±1시간 버튼을 사용합니다. 다음날 취침은 명시적으로 선택하고, 같은 취침·기상 시각의 0시간과 24시간도 구분합니다. 변경 미리보기에서 수면 길이와 시간 계산을 확인한 뒤 **적용**합니다. 취소하면 저장된 값이 유지됩니다.

기존 기록은 그대로 보존합니다. 옛 저장값에는 직접 정한 값과 앱이 넣은 기본값을 구분할 근거가 없으므로, 9시간·23:30을 포함한 유효한 기존값을 보여주고 확인을 유도합니다. 열기·날짜 선택·새로고침만으로 값을 변경하지 않습니다.

활동·준비·이동 숫자도 같은 조절창에서 **예상 소요시간**으로 조정합니다. 소요시간은 0분을 허용하며, 시각과 구분합니다. 새 계획의 제안값은 실제 실측 기록이 아닙니다. 기존 계획의 변경은 적용한 뒤 저장하고, 실제 시작·종료 로그는 덮어쓰지 않습니다.

## 화면과 실제 기록

첫 화면은 시간, 현재 단계의 한 가지 행동, 작은 오늘 기록으로 단순하게 유지합니다. 준비·출발·도착·활동·마무리·귀가의 실제 단계는 눌렀을 때의 현재 시각만 기록합니다. 예상 시간 경과로 다음 단계를 자동 완료하지 않습니다. 세부 기록창에서 단계 생략과 실제 시각 수정·취소를 할 수 있습니다.

실제 미확인 구간은 0분으로 단정하지 않습니다. 표시된 합계는 기록한 구간의 부분 합계일 수 있습니다. 옛 `활동 끝 → 귀가`는 마무리와 귀가 이동을 합친 기록으로 유지하고 임의로 나누지 않습니다. 휴식도 같은 규칙을 쓰며 점수나 연속 달성은 없습니다.

**취침까지 남은 시간**은 계획을 빼지 않습니다. 미설정이면 설정을 유도하고, 취침 이후는 0분, 미래 날짜는 예정 시각을 표시합니다. 명시한 다음날 취침은 자정 후에도 그 취침 시각까지 이어집니다. 상세 화면의 **하루 미배정 예산**은 `24시간 − 날짜별 수면 − 준비·이동·활동`으로 이미 지난 시간도 포함합니다. **지금부터 열린 시간**은 현재부터 자정까지 수면과 계획이 없는 구간이며, 미래는 하루 전체, 과거는 0분입니다. 계산 근거가 부족하면 설정 후 계산으로 표시합니다. 이름 없는 시간은 낭비 판정이 아닙니다.

## 구조와 검사

- `index.html`, `styles.css`: 화면과 모바일·접근성 스타일
- `app.js`: 화면·저장소 연결
- `core.js`: 시간 계산·백업 검증·실측 구간 해석
- `time-controls.js`: 시각·소요시간 조절창, 초안·미리보기·적용·취소
- `tracking.js`: 실제 단계 기록·생략·시각 수정·복구
- `tests/`: 핵심 계산·단계 전이·격리 브라우저 검사
- `DATA_CONTRACT.md`: 웹과 향후 iOS·Android의 공통 데이터 규칙
- `VERIFICATION.md`: 기존 배포판과 이번 수정본의 검사 결과·대기 항목

```bash
npm test
node tests/tracking.test.js
python3 tests/touch.browser.test.py
python3 tests/mobile.browser.test.py
```

Python Playwright·Chromium 검사는 새 컨텍스트와 합성 기록만 사용합니다. 시스템 Chromium을 쓸 때는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium`을 지정할 수 있습니다. 클라우드 재현 명령과 최종 결과는 [VERIFICATION.md](VERIFICATION.md)에 있습니다. 실제 사용자 브라우저 데이터를 읽거나 변경하지 않습니다. R530에서는 가벼운 검사부터 시작하고 80°C에 도달하면 부하 작업을 중단합니다.
